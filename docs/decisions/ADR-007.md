# ADR-007: 构建开启 noEmitOnError，测试使用 Node 内置 node:test

## Status: Accepted (2026-09-21)

## Background
TypeScript 默认在存在类型错误时仍会 emit 产物，导致「构建看起来过了」的假象；而引入 jest/vitest 会增加依赖与版本对齐风险。

## Decision
基础 tsconfig 显式开启 noEmitOnError（带错不出产物）；测试用 Node 22 内置 node:test + node:assert，零测试依赖；测试脚本统一使用 glob 形式 node --test "dist/**/*.test.js"。

## Consequences
- 正面：构建结果可信；测试零依赖、离线可跑；避免目录参数被解析成模块的兼容性问题。
- 负面：需先编译再测试（build 前置），CI 顺序固定。
