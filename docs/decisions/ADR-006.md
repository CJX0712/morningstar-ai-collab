# ADR-006: 图标唯一源锁定 lucide-react，禁用 emoji 作功能图标

## Status: Accepted (2026-09-21)

## Background
P0 规则要求图标统一描边、可缩放、语义明确，禁止 emoji 充当功能图标，且不得混用多套图标库。

## Decision
全项目唯一图标源 lucide-react 1.46.0，尺寸 16/20/24px、strokeWidth 1.75、stroke currentColor；语义状态图标固定为 CircleCheck / TriangleAlert / CircleX / Info / LoaderCircle；OAuth 按钮使用文字商标 + 中性图标 KeyRound，不引入品牌 logo 图标库。

## Consequences
- 正面：视觉统一、可 tree-shake、无 emoji 违规。
- 负面：品牌 logo 需另建 SVG 资产库（已标注为品牌资产例外）。
