# ADR-004: 嵌入器默认使用确定性哈希嵌入，并对 CJK 采用字符 bigram

## Status: Accepted (2026-09-21)

## Background
需要离线可复现的嵌入；且中文文本没有空格，按整串切词会导致查询词与文档 token 完全不重合，余弦恒为 0。

## Decision
Embedder 协议默认 HashEmbedder：拉丁文本按词切分，中日韩文本切字符 bigram，再做确定性哈希投影；生产可切换 RemoteEmbedder（OpenAI 兼容 /v1/embeddings）。

## Consequences
- 正面：零下载、零 Key、结果可复现；中文短查询也能命中。
- 负面：语义泛化能力弱于真实嵌入模型；生产应切换 RemoteEmbedder。
