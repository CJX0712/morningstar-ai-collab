# ADR-001: 采用 npm workspaces 的 TypeScript 单体仓库

## Status: Accepted (2026-09-21)

## Background
需要在同一仓库内管理 1 个前端 + 5 个后端服务，并要求跨服务共享唯一契约、干净环境可一键复现。

## Decision
使用 npm workspaces（Node 22 自带 npm 10）管理 packages/contracts 与 apps/*，依赖 exact 钉版本并提交 package-lock.json，复现命令为 npm ci。

## Consequences
- 正面：零额外工具链；契约以 workspace 包形式被各服务直接引用；npm ci 可精确复现。
- 负面：相对 pnpm，磁盘占用与安装速度略逊；初始方案为 pnpm 10，但目标环境中 pnpm 与 corepack 均不可用，故改为 npm workspaces（复现性等价）。
