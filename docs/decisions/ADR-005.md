# ADR-005: ai-gateway 以 OpenAI 兼容协议为唯一抽象面

## Status: Accepted (2026-09-21)

## Background
需要同时支持本地 Ollama、云端 OpenAI/DeepSeek 与 vLLM，且不能把模型供应商耦合进业务代码。

## Decision
ai-gateway 内部只使用 OpenAI 兼容的 /v1/chat/completions 协议，通过环境变量在 mock / ollama / openai 三种 provider 间切换；未配置或调用失败时降级，保证链路不中断。

## Consequences
- 正面：一套客户端热切 provider；Ollama 与云端体验一致；失败可降级。
- 负面：暂未使用 LangChain.js 等编排框架（降低依赖树与版本对齐风险），复杂 Agent 编排留待后续引入。
