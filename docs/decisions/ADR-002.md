# ADR-002: 后端按单一职责拆分为 5 个可独立部署的服务

## Status: Accepted (2026-09-21)

## Background
四大 AI 能力（对话/Agent、RAG、会议纪要、代码任务助手）与协作核心的差异很大：模型、依赖、伸缩策略都不同。

## Decision
拆分为 collab-core / ai-gateway / rag-service / meeting-summary / code-task-assistant，各自独立端口、独立 boot、独立测试；跨服务通过 packages/contracts 的类型契约协作，同步调用走 typed HTTP。

## Consequences
- 正面：每个模块可独立验证、独立伸缩、独立替换实现；故障域隔离。
- 负面：进程数增加，本地启动需并行拉起；已用 docker-compose 与健康检查抵消。
