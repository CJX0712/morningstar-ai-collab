# ADR-003: 向量库主选 Qdrant，默认实现为进程内内存存储

## Status: Accepted (2026-09-21)

## Background
RAG 需要向量检索；但交付要求「干净环境一键复现」，不能强依赖外部数据库或 GPU。

## Decision
定义 VectorStore 协议：默认 MemoryVectorStore（进程内余弦检索），生产切换 QdrantVectorStore（REST API，零 SDK 依赖，镜像钉 v1.13.6）。

## Consequences
- 正面：无 GPU、无外部依赖即可跑通并测试检索链路；生产仍可用成熟向量库。
- 负面：内存实现不持久化，重启后需重新灌入；已通过 docker-compose 的 qdrant profile 给出生产路径。
